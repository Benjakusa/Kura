# KuraLive

**KuraLive** is a secure, real-time vote reporting application designed for managing and aggregating election results across multiple independent elections. It enables election managers to create isolated subsystems, assign agents to polling stations, collect verified results, and include photographic proof of official result forms (converted to PDF).

Developed for transparency, accuracy, and ease of use in elections, organizational voting, community polls, and similar processes.

## Features

- Isolated subsystems for each election manager  
- Freemium model: free registration + one full election trial; $299 one-time payment for unlimited access  
- Role-based access: Managers (full control) and Agents (simple data entry)  
- One-time submission locking for station details and results (with manager reset capability)  
- Photo capture → PDF conversion → upload to manager dashboard  
- Real-time cumulative results with turnout %, spoilt/rejected votes, charts & regional breakdowns  
- Export reports (CSV/PDF) and uploaded form gallery  
- Input validation and audit logging for integrity

## User Roles & Flows

### Election Manager
1. Register (free) → receive unique subsystem  
2. Use trial or pay $299 for full access  
3. Create election, add polling stations & candidates  
4. Create and assign agents (generate credentials)  
5. Monitor live results, view uploaded PDFs, reset agent submissions if needed  
6. Export final reports

### Election Agent
1. Receive credentials from manager  
2. Log in → see assigned polling station  
3. Submit **Station Details** (once): location, registered voters, candidates  
4. Submit **Results** (once): votes per candidate, spoilt/rejected + photo of result form  
5. Data locks after submission (only manager can reset)
